# Documentación del proyecto

Este directorio reúne los entregables y documentación de soporte del TFM,
complementarios al código fuente:

- Entregables formales (Design Thinking, Scrum/Lean, arquitectura, validación
  experimental) se gestionan en el documento colaborativo del equipo en
  Google Drive (`Entrega_2_V1_3012G`) y se exportan aquí en los hitos de
  entrega.
- `architecture.md` — diagrama y descripción de la arquitectura del sistema
  (Cap. 5.1).
- `test-protocol.md` — protocolo formal de pruebas y baseline (Cap. 6.1).

Añade aquí cualquier diagrama, acta de reunión o evidencia (capturas de Jira,
Slack, Teams) referenciada en el TFM.
